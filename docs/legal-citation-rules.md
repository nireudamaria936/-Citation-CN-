# 法引规则库

本项目的 WPS 检查器以用户提供的《法学引注手册》（2019 年 11 月版）为规则来源。规则被拆成两层：`lib/legal-citation-rules.js` 保存可追踪的规则摘要和规则编号；`lib/citation-checker.js` 执行能够从文档纯文本中可靠判断的格式检查。规则提示均属于格式建议，不会验证文献是否真实、版本是否权威、页码是否准确，也不会自动判断引用是否“必要”。

## 规则覆盖

| 规则组 | 覆盖内容 |
| --- | --- |
| G | 页下注、连续编号、引注符号位置、参见/见/载/转引自、中文标点、多个文献、多次引用、图表和夹注、结尾标点 |
| CN | 中文图书、期刊、文集、报纸、网络/电视/音像、学位论文、会议论文、访谈、私人通讯、内部资料、档案 |
| LAW | 中文法律、法规、规章、规范性文件、国家标准、立法说明、会议决议、外国法/国际公约、台湾地区文件 |
| CASE/STAT | 民事、行政、刑事案例名称，法院、案号、案例来源、裁判时间，统计数据和图表来源 |
| EN | 英文学术期刊、报刊、图书、文集、美国联邦法规、美国/英国案例、网络文献 |
| FR | 法文学术文献、法国法律、法国法院判决、法文网络信息和重复引用 |
| DE | 德文学术文献、德文法规、德文案例、德文网络文献和后续简写 |
| JA | 日文书籍、论文、文集、案例、法规、官方文件和网络文献 |

## 程序会自动修正的典型问题

- 中文引注末尾缺少句号，或误用英文句号；外文引注末尾缺少西文句号。
- 规范性文件号误用 `[2007]`/`【2007】`，统一建议为 `〔2007〕`；中文案例年份统一建议为 `（2007）`。
- 连续页码误用长横线或波浪线，统一为 `第73-75页`。
- 中文标点两侧多余空格、出版社与年份之间多余空格。
- 中文法律名称在不引起误解时去除“中华人民共和国”；中文初版不保留“第1版”。
- GB/T 7714 的图书、期刊、学位论文、网络文献、法律文件等标记，可转换为手册的中文法学引注格式。

## 需要人工确认的典型问题

- 引注是否确有必要、来源是否真实相关权威、是否应优先引用纸质原初来源。
- 同一文献再次出现时是否使用“同上注”、前注序号、`Ibid.`、`op. cit.` 或德文/日文习惯简写。
- 英文、法文书名/文章名的斜体、法文 `« »`、德文 `S./f./ff.`、日文 `『 』/「 」` 等字体或排版属性。
- 案例案由、法院全名、案号零位、指导性案例/公报来源和裁判日期。
- 外国法规和案例的报告系统、法典版本、条款层级、译者和官方文本。
- 访谈、私人通讯、内部资料、会议论文、档案和自媒体是否取得同意、是否存在更权威的已发表版本。

规则编号会显示在 WPS 检查结果中，例如 `LAW05` 表示规范性文件号，`CASE02` 表示案例案号，`EN04` 表示美国联邦法规，便于人工复核和后续扩展。
